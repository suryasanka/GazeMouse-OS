Architecture & Pipeline

How GazeMouse-OS Works

From raw webcam frames to responsive game inputs — a refined three-stage optical pipeline operating entirely within your browser.

01

Detect

The webcam detects facial landmarks to support head tracking.

Using the browser's local getUserMedia API and Google MediaPipe Face Landmarker via WebAssembly and WebGL, the system detects 478 3D facial landmarks at 30 to 60 FPS. Anchor coordinates from the nose tip, eye corners, and chin are isolated in real time.

MediaPipe · WebAssembly · WebGL
02

Interpret

The application interprets head movements and recognizes supported directional gestures.

Relative displacement vectors (ΔX, ΔY) are calculated against the player's personal neutral baseline, normalized by inter-pupillary distance. Exponential moving averages smooth out sensor noise, while a calibrated dead-zone filters micro-tremors and natural chin dips.

Vector Normalization · EMA Filter · Hysteresis
03

Play

Recognized gestures can control compatible games through the relevant input mechanism.

Filtered gestures trigger game actions: steering lanes in 2D/3D endless runners, controlling floating dwell cursors in puzzle grids, or dispatching DirectInput scancodes through the local Windows desktop bridge to approved external game windows.

HTML5 Canvas · Three.js · Win32 DirectInput
Core Capabilities

Engineered for Freedom & Precision

High-performance assistive technology designed to make gaming accessible through comfortable, customizable head interaction.

Real-Time Face and Head Tracking

Lightweight neural inference tracking 478 3D facial landmarks at 30–60 FPS. Powered by WebAssembly and WebGL to run smoothly on standard laptops without proprietary eye-tracking hardware.

● MediaPipe Face Landmarker

Center Calibration

Instantly zero your baseline resting posture with a single click. Adapts to your natural seating angle, tilt, and webcam mounting position so you never need to force an unnatural head angle.

● Personalized Zero-Delta Baseline

Directional Gesture Recognition

Biomechanical classifier translating intentional yaw (lateral turns) and pitch (vertical deflections) into discrete actions. Hysteresis ensures you must return to neutral before triggering again.

● Anti-Double-Trigger Hysteresis

Hands-Free Gaming Controls

Play complete games using only natural head gestures. Whether steering down high-speed 3D tracks or selecting puzzle tiles with dwell-timing, zero keyboard or mouse interaction is required.

● Native Full Hands-Free Input

Desktop Input Bridge

Standalone Python 3 daemon for Windows 10/11. Translates web head gestures into DirectInput scancodes for external applications with loopback-only sockets, session tokens, and hardware emergency stop.

● Python 3 · Win32 SendInput · RFC 6455

Accessibility-Focused Interaction

Consciously built to WCAG AA guidelines with high contrast, clear keyboard focus outlines, customizable dead-zones to eliminate fatigue, auto-pause on face loss, and full keyboard fallbacks.

● WCAG AA Compliant · Auto-Pause

Uncompromising Privacy

Zero Video Leaves Your Machine

GazeMouse-OS is engineered around strict local privacy principles. Your camera stream is never uploaded, recorded, or transmitted to any external server.

100% On-Device WebAssembly Inference

All facial landmark estimation occurs locally in your browser's WebAssembly and WebGL execution context. Raw video frames exist solely in volatile client RAM.

Explicit Browser Permissions & No Accounts

No user accounts, subscriptions, or telemetry trackers exist. The webcam only activates after you explicitly click "Enable Camera", and you can revoke browser permissions at any time.

Hardware Emergency Stop & Loopback Isolation

The optional desktop bridge binds strictly to localhost (127.0.0.1) and is protected by Windows NTFS user ACLs. Pressing Ctrl + Alt + Q anywhere instantly halts all input injection.

Inclusive Design

Accessibility Highlights

GazeMouse-OS adheres to WCAG 2.1 AA accessibility guidelines to ensure a frictionless, dignified experience for all players:

  • ✓ High-Contrast Aesthetics: Exceeds 4.5:1 contrast ratios on all text and UI elements for effortless readability.
  • ✓ Visible Keyboard Focus: Distinct high-visibility focus indicators on all interactive controls for keyboard-only navigation.
  • ✓ Reduced Motion Support: Respects the system prefers-reduced-motion setting, disabling ambient motion effects and loops.
  • ✓ Adjustable Dead-Zones: Fine-tune resting sensitivity thresholds to match individual comfort and prevent neck strain.
  • ✓ Auto-Pause Protection: Games automatically freeze if the face leaves the webcam frame, preventing accidental losses.
  • ✓ Keyboard Fallback Controls: Every game includes fully mapped keyboard controls as an alternative to head movement.
